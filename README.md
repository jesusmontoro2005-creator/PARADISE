Nombre del proyecto: Agencia paradise
Proyecto para agencia de viajes  "Paradise", gestiona viajes nacionales e internacionales 
objetivo: Realizar una aplicacion web para la agencia de viajes "paradise", en un periodo de cuatro meses con la metodologia scrum, html, css y sql
## FUNCIONALIDADES
-{} Gestion de usuarios
-{} Gestiion de viajes nacionales
-{} Gestion de viajes internacionales
-{} gestion de tours
-{} Gestion de reportes
